# MayFilm Studio — GitHub Pages

Static migration of the original Wix website. Open `index.html` locally to preview.

## Publish with GitHub Desktop

1. Copy everything inside this folder into the local GitHub Pages repository folder.
2. In GitHub Desktop, enter the summary `Migrate MayFilm Studio website`.
3. Click **Commit to main**, then **Push origin**.
4. On GitHub, open **Settings → Pages** and select **Deploy from a branch → main → /(root)**.
